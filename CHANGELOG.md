# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2025-06-01

### Added
- Initial release of `friday`.
- `AGENTS.md` with common rules (Conventional Commits, US/BDD, PRD/SPEC, DoD).
- `project.model.md` — project contract template (platform, repo, branch, sprint, etc.).
- `instalar.sh` — global installer with `--remover`, `--force`, `--init-project`.
- Skills: `issue` and `pr` (with platform files for github, gitlab, ado).
- Agents: `dev`, `tester`, `reviewer`, `redator`, `analista`.
